# 📦 Project Status – CI/CD Docker Bootstrap

## 🎯 Scopo del progetto

Creare uno script universale (`start.sh`) che:

- funzioni su qualsiasi ambiente Linux
- rilevi automaticamente l'ambiente (local, GCP, Killercoda)
- selezioni il Dockerfile corretto
- costruisca una Docker image
- sia eseguibile subito dopo clone del repository

---

## 🚀 Modalità di utilizzo

```bash
git clone <repo>
cd <repo>
chmod +x start.sh
./start.sh
``
